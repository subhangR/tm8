04Keep the identities; share the work

  • The message is durable. Posting to a session anchor creates a graph message before delivery.
  • The turn is identified. The running session receives the author identity and graph message id with the next turn.
  • The reply keeps context. Reply threading records which question the response belongs to.
  • The process stays singular. Everyone sees the same PTY; they are steering one running teammate, not creating copies.
