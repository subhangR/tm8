The left controls choose whether a blueprint node is a spec for a future task or a ref to the existing Ship invite flow task. A ref draws a connection to that task. A spec stays dashed and should contain only kind, title, and a lean hint.


    
The rule: if the entity exists, use ref and point to it. If it does not, use spec and sketch only what agents need to recognize the work.
