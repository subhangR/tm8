02Two edges, two meanings

Use the narrow relation that says what you mean. A skill is capability selection; a document is context. They can sit beside the same teammate without becoming the same thing.

equips
Directed from task, team_member, or work_session to a skill or spell. It feeds capability selection into launch composition.
attached_to
Context attachment. Docs and files use this edge rather than equips. An attachment does not enter the manifest’s skills array.
real edge syntaxpty
tm8 edge create <teammate-id> equips <skill-id>
tm8 edge create <doc-id> attached_to <teammate-id>

03What reaches the session

The spawn path walks Callisto’s teammate hierarchy, resolves equipped skills nearest-first, and renders each winning skill’s name and body into the stable manifest field. The method arrives as prompt material—not as a new permission.

nearest winsA child teammate’s same-named skill shadows the ancestor version.
same entityThe same skill equipped at several levels appears once.
ambiguousTwo different, same-named skills at the same depth refuse instead of choosing silently.
limit · 64The nearest 64 enter the manifest; dropped names are reported, not hidden.

04Keep the boundary honest

Instruction is not authority.Equipping Accessibility QA supplies a method to the agent prompt. It does not change accessMode, command permissions, provider, model, or available tools.
Spell runtime gap.equips accepts a spell selection in the graph. The current launch path shown here resolves skills; it does not inject or cast spells. That is why Release ritual stays in ghost ink.
