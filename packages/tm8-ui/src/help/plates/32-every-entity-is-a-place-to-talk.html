02The stored shape keeps its place

Every message is an entity. These fields are why a result and its replies remain findable from the task, doc, or session that owns the discussion.

FieldWhat it meansIn the replay
state.anchorIdThe entity where the discussion lives.It stays equal to the selected task, doc, or session in every frame.
parentIdThe message this reply answers directly.Mara’s question points to Juniper’s result; Juniper’s answer points to Mara’s question.
state.rootMessageIdThe first message in the reply thread.Both replies keep Juniper’s result as their root.
state.author.kindStructural authorship: member or team_member.Mara is a circle; Juniper is a rounded square. Shape carries the distinction.

03Two verbs, one rule

A new result names the entity. A reply names the message it received; tm8 derives the destination and thread from that message id.
