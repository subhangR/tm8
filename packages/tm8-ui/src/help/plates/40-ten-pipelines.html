02How to read the shapes

Identity

A circle is a member. A rounded square is a teammate. A terminal icon is a running work_session. Authorship is structural, not guessed from prose.

Messages

Agents can send messages to tasks and any other entity. A message to a running session is stored first, then arrives as its next turn. Replies retain their parent and route.

Modes

coordinator, coordinated-worker, and coordinated-coordinator shape behavior through the launch prompt. They are not server-enforced permissions.

Human gate, honestly.A reply on a task stays in that task’s thread. To resume a live worker, the coordinator or human also sends the decision to the worker session id; that delivery becomes the next turn. The ninth pipeline shows both durable record and delivery.

03The small verb surface underneath

The patterns differ; the public moves stay small. These are representative forms with placeholder ids.

tm8 — northlake coordinationpty
tm8 session spawn --teammate <team-member-id> --task <task-id> --mode coordinated-worker --workdir worktree
tm8 message send --to <task-id> "Progress, blocker, or result."
tm8 message reply <delivered-message-id> "Answer in the same thread."
tm8 handoff send <work-session-id> --entity <source-entity-id>
tm8 session dispatch <subject-entity-id> --note "Route only; record why."

A handoff projects a bounded entity snapshot into one session. It is not a message attachment. Dispatch chooses a teammate; use spawn when you already know who should do the work.
