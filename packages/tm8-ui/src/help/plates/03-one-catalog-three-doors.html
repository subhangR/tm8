01Equivalent does not mean identical

CLIYou choose the operation.

The command maps directly to a catalog entry. Output is explicit and scriptable.

UIThe control chooses it.

A form or composer supplies typed fields, then the UI listens for Space events and re-renders.

CHATA teammate chooses it.

Your sentence is intent, not an API shape. A running teammate interprets it and calls an allowed operation.

Honest boundary.The CLI is not a live view. Event fan-out does not redraw your terminal; a later entity get, entity context, or event poll reads the new state. The UI can update from the event stream. Chat adds an interpreter hop before the same catalog call.

02What is shared

  • Authorization and input validation happen at the server boundary, whichever surface begins the request.
  • The graph write is durable. Creating a task yields an entity at version: 1 plus an activity record; posting a message yields a batch plus message entities anchored to the target.
  • The Space event is the handoff. UI subscriptions can update immediately; CLI reads and later Chat context observe the same stored graph.
