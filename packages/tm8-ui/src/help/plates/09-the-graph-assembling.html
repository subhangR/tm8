01The shape that remains

At rest, the graph says who owns the work, what informs it, what is running, and where the conversation lives.

    doc → task · attached_toThe notes join the task’s context.

03One distinction worth keeping

A teammate is who; a session is now. Juniper is the durable agent persona. “Juniper · now” is one running instance, working on one task in this graph.
