§10 · ACCESSIBILITY CONTRACT — CARRIED BY THE BUILD, NOT THE MOCK
· The switch is a tab list labelled "Work session surface" — arrows/Home/End move tabs; a failed Chat tab stays discoverable with a textual reason. · Terminal focus law: a focused terminal eats every key except Ctrl+`, which parks focus on the Content tab header. Nothing else steals keys from it. · The feed is a labelled chronological list of articles — no ARIA chat semantics the virtualizer can't honour. Author, direction, provenance, delivery, redaction: all available as text. · Send state and delivery state are announced as separate events. Reduced motion, high contrast, 200% zoom, keyboard-only: release requirements.
