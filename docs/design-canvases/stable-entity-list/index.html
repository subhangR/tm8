Move entity

Choose a parent. It will become the first child.

Stable by default

Every kind uses the same placement rules. A parent contains entities of its own kind. Moving a parent brings its whole subtree.

New / Add child
Insert at the top and open a draft detail tab. Enter commits the title; Escape cancels a new draft.
Long press a card
Hold briefly to pick it up. A quick click still opens it; a swipe still scrolls. Drop above/below to reorder; in the middle to nest. Escape cancels. The preview slides surrounding rows.
Row menu
Move to…, move up/down, indent and outdent provide alternatives to dragging.
Alt + ↑ / ↓
Move a focused row up / down.
Alt + → / ←
Indent / outdent a focused row.
Search
Shows matches with ancestors. Clear search to move items in the complete tree.

This study uses local demo data. Session creation stands in for the existing launch flow; no agent is launched. Production integration needs shared persisted sibling order and existing permission/version checks.
