TM8 Mobile
A native app for the whole work graph.

The design and low-level design of a new React Native app for tm8: every server you belong to, every space on it, every one of the 33 entity kinds, the agents that run inside them, and a chat you will want to live in — drawn at device size for iPhone and Android, light and dark, with the routes, states and gestures that make it an app rather than a website in a frame.
