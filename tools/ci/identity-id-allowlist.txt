# The identity_id() allow-list (plan 01a0d9eb §3 W3, F7), read by tools/ci/identity-id-gate.sh.
#
# One line per live function that reads the caller's identity, as
#   <reader> <schema.name(identity args)>
# where <reader> is `identity_id` (calls internal.identity_id()) or `setting`
# (reads the raw tm8.identity_id setting). The gate fails on a live function
# missing from this list AND on a line here that matches no live function.
#
# Adding a line is a security review. Such a function decides for itself whether
# the caller may act, so check that it cannot reach a space other than the pinned
# one (internal.session_space_id(), 227): it goes through a pinned membership
# helper, RLS as tm8_app, node admin (pinned out by 231), or touches only the
# caller's own account rows. Put the verdict in the trailing comment.
#
# Tags: PIN-HELPER, ACCOUNT, GUARDED, NODE-ADMIN, KNOWN-GAP (see the W3-audit
# matrix in packages/server/test/db/cross-space-token.pg.test.ts).
