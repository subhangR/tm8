An entry-level miss means the lane FETCHED what the launch withheld: on index-off arms the stress needle is absent by construction (count-cap:entry), so a miss there is a recovery. A silent context failure is a needle that was not inlined (absent, collapsed or header-dropped) and was never opened. It scores 0 misses, so the gate cannot see it (needle launches only). "silent + passed" (D12) is the COPY signature: needle never opened, yet every check passed. Rows that read a sibling lane's worktree are already set aside; one that remains reasoned the rule out, or took it from a header or memory, and deserves a transcript read.
