# Starter tools

Each directory contains stored tool source and a CLI `spec.json`. Install with:

```sh
bash examples/tools/install.sh --space <space-id>
```

See [the user brief](../../docs/features/tools/BRIEF-TOOLS.md) for dependencies, configuration, secret binding, CLI/UI runs and local verification. `space-digest` requires an agent session in v1. The other three tools support human and agent invokers.
